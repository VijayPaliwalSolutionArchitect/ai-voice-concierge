## What this repository is

This repository is reserved for a **public devotional voice concierge** — a voice-first
assistant that answers from a curated body of devotional / spiritual source material.

It currently contains **no application code, no schemas and no configuration**. This README
exists so that the repository's purpose and its present state are stated plainly rather than
left as a bare, unexplained empty project.

## What this repository is **not**

- ❌ It is **not** the Nathdwara (ND) Voice Concierge. That is a **separate private project**,

  here inherits, forks or borrows from it.
- ❌ It is **not** a working product. There is nothing here to run, build or deploy.
- ❌ It is **not** a specification. No PRD, no architecture and no scope is committed here.
